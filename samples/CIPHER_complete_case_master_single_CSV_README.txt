CIPHER Complete Case – Single Master CSV

This file combines all records from the complete end-to-end synthetic test dataset into ONE CSV. The first column, record_type, identifies what each row represents (case, node, relationship, evidence, location, observation, event, review_queue, audit_log, ai_test_issues, or test_cases). Blank cells are expected where a field does not apply to a particular record type.

Use this as a single test/import dataset. It is synthetic data for application testing.
Do not treat the records as real investigative data.
